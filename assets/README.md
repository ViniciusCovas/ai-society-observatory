# Recursos de marca

Coloca aquí dos ficheros y la portada los mostrará automáticamente
(si faltan, la página funciona igual con tratamiento tipográfico):

- `anahuac.png` — logotipo de la Universidad Anáhuac (fondo transparente, alto ≥ 92 px).
- `avatar.jpg` — retrato del investigador (cuadrado, ≥ 200×200 px).

Nota de uso: el logotipo institucional es marca de la universidad. Confirma con
Comunicación Institucional / tu centro antes de publicarlo en un sitio de proyecto,
para que la identidad visual quede correctamente autorizada.
